# PARTE II — DOUTRINAS

# ASTERION — DOUTRINAS
## Regras e UX Fechadas

### 1. Conceito

Doutrinas são builds salvas do personagem.

Cada Doutrina reúne:
- Equipamentos
- Artes Ativas
- Talentos

O jogador pode criar diferentes Doutrinas para adaptar sua configuração a diferentes situações.

Apenas uma Doutrina pode estar em uso por vez.

---

### 2. Tela principal

```text
🗂️ **Doutrinas**

*Crie e salve diferentes configurações para usar em diferentes situações. Cada Doutrina reúne seus Equipamentos, Artes e Talentos em uma única build.*

🟢 `PvE`    🔴 `PvP`
🔴 `Caçada`   🔴 `Arena`

⚠️ Pode criar diferentes Doutrinas para adaptar a cada desafio. Apenas uma Doutrina pode estar em uso por vez.

[ 🟢 PvE ] [ 🔴 PvP ]
[ 🔴 Caçada ] [ 🔴 Arena ]
[ ➕ Criar ]
[ ↩️ Retornar ]
```

#### Estado
- 🟢 indica a Doutrina atualmente em uso.
- 🔴 indica as demais Doutrinas.
- Não escrever “Ativa” ou “Inativa”.
- Apenas uma Doutrina pode estar em uso por vez.

#### Layout simétrico
A listagem deve usar duas colunas de largura fixa e exatamente igual:

| Coluna esquerda | Coluna direita |
|---|---|
| 🟢 PvE | 🔴 PvP |
| 🔴 Caçada | 🔴 Arena |

Não usar quantidade variável de espaços para produzir alinhamento. Implementar duas colunas fixas e simétricas.

- `🌿 Talentos` abre diretamente a distribuição de Talentos.
- Evitar mensagens intermediárias desnecessárias.
- Usar edição da mensagem atual quando esse for o padrão da interface.

Caminho não faz parte da interface de Doutrinas/builds nesta versão.

Não incluir Caminho:
- no resumo da Configuração;
- no menu de edição;
- na criação;
- em qualquer seção de Doutrina.

- Nomes e valores indicados como mono devem usar monoespaçado.
- Manter a hierarquia visual das demais telas de Asterion.
- Usar 🟢/🔴 para o estado das Doutrinas.
- Não substituir os indicadores por “Ativa/Inativa”.
- Manter o layout de duas colunas da tela principal simétrico.

---

### 12. Regras de implementação

- Não inventar regras mecânicas.
- Não alterar termos fechados sem autorização.
- A quantidade de Talentos ativos na Configuração é dinâmica.
- A Configuração deve refletir exatamente os dados salvos da Doutrina.
- Apenas uma Doutrina pode estar em uso.
- Os exemplos acima não devem ser hardcoded como dados reais do jogador.
- A edição de Talentos deve respeitar os requisitos e estados definidos.

# PARTE III — RELAÇÃO ENTRE OS SISTEMAS

Esta seção apenas conecta as informações dos dois documentos, sem substituir ou remover nenhuma regra dos documentos de origem.

## Equipamentos dentro de Doutrinas

A Doutrina salva a configuração de Equipamentos do personagem.

A estrutura de Equipamentos usada na Doutrina segue as posições definidas no documento de Equipamentos:
- Principal
- Secundária
- Cabeça
- Torso
- Mãos
- Pés
- Acessório
- Artefato

O documento de Equipamentos define essas posições e a interface correspondente. fileciteturn368file0L4-L23

A Doutrina utiliza essa mesma estrutura para salvar uma configuração específica de build. fileciteturn368file1L55-L90

## Artes dentro de Doutrinas

O sistema geral de Artes possui Artes Equipadas e Artes Conhecidas, com detalhe individual e regras de equipagem. fileciteturn368file0L106-L161

Dentro de uma Doutrina, são salvas três Artes Ativas:
- Arte 1
- Arte 2
- Arte 3

A interface da Doutrina usa os nomes `Arte 1`, `Arte 2` e `Arte 3`, sem usar “Slot” como termo player-facing. fileciteturn368file1L104-L133

O documento geral de Artes também preserva o fluxo de equipagem direta por posição e o retorno à tela de Artes. fileciteturn368file0L131-L161

## Talentos dentro de Doutrinas

Talentos fazem parte da build salva pela Doutrina. fileciteturn368file1L6-L15

Na tela de Configuração da Doutrina, devem aparecer **somente os Talentos atualmente distribuídos/ativos naquela Doutrina**. A quantidade é dinâmica e todos os Talentos ativos devem permanecer na própria tela, mesmo quando houver cinco, seis ou mais. fileciteturn368file1L93-L100

A tela de edição/distribuição é separada do resumo da Configuração e apresenta os Talentos disponíveis organizados pelos requisitos de nível. fileciteturn368file1L137-L211

## Inventário e Doutrinas

O Inventário permanece como sistema geral de posse e organização de itens, enquanto a Doutrina representa uma configuração salva do personagem. O documento de Inventário define categorias, espaço, entregas pendentes e acesso ao Armazém. fileciteturn368file0L49-L72

A Doutrina não substitui o Inventário. Ela salva a configuração que será utilizada pelo personagem.

## Materiais

Materiais continuam pertencendo ao Inventário/Materiais e não fazem parte da configuração de uma Doutrina. O documento de Materiais define listagem, paginação, detalhe e regras de apresentação. fileciteturn368file0L74-L105

## Regras visuais compartilhadas

Os dois documentos trabalham com:
- títulos em negrito;
- narrativas e descrições em itálico;
- valores em monoespaçado;
- botões com emoji;
- paginação para listas extensas;
- `↩️ Retornar` como padrão;
- cuidado com listas extensas e organização visual.

As regras gerais de Inventário, Materiais e Artes permanecem preservadas integralmente na Parte I, enquanto as regras específicas de Doutrinas permanecem preservadas integralmente na Parte II. fileciteturn368file0L163-L173

## Observação sobre termos preservados

Como esta consolidação não remove nenhuma informação dos documentos de origem, eventuais diferenças de terminologia entre um documento e outro permanecem registradas nas respectivas partes originais. Nenhuma delas foi silenciosamente alterada ou descartada nesta consolidação.

## 8. Regras Gerais da Área

- Não existe mais tela `Perfil`.
- `História` é a tela diretamente acessível.
- Usar o mesmo padrão visual de Perfil anteriormente definido nas telas em que o personagem é exibido.
- Títulos sempre em **negrito**.
- Textos narrativos e descritivos em *itálico*.
- Valores e informações técnicas em `monoespaçado` quando aplicável.
- Quando o personagem for exibido, usar o padrão definido: emoji de identidade + nome + nível, seguido de classe e título, quando aplicável.
- TAG de Guilda, quando existir, aparece junto ao nome: `🛡️ **[AUR] Olev** · Nv. 1`.
- Não usar números soltos como botões.
- Usar emojis que representem claramente cada categoria.
- Cosméticos possuem tela de detalhes antes da ação `✅ Usar`.
- Detalhes de Aparência, Títulos e Molduras usam `✨ Raridade` e `🌐 Origem`.
- Feitos possuem tela de detalhes, mas não possuem botão `Usar`.
- `✨ Raridade` é o padrão para raridade.
- `🌐 Origem` é o padrão para procedência.
- `✅ Usar` é o padrão para equipar cosméticos.
- `↩️ Retornar` é o padrão de retorno.
- Transições devem editar a mensagem atual, evitando mensagens intermediárias desnecessárias.
- Entradas de texto temporárias devem desaparecer após conclusão ou cancelamento.
- Nunca deixar prompts antigos de entrada de texto acumulados no chat.
